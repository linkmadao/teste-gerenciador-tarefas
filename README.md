# Gerenciador de Tarefas
Sistema de gerenciamento de tarefas destinado a auxiliar os usuários na organização e acompanhamento de suas atividades diárias, bem como na colaboração com outros membros da equipe.

### Informações do teste
Empresa: [EclipseWorks](https://eclipseworks.com.br)

[Teste proposto pela empresa](https://meteor-ocelot-f0d.notion.site/NET-C-5281edbec2e4480d98552e5ca0242c5b)

### Informações sobre a arquitetura do software
Framework: .NET 8 (LTS)
Arquitetura de Software: Arquitetura em Camadas
ORM: EntityFrameworkCore
Principios de Design: SOLID, KISS, DRY, YAGNI
